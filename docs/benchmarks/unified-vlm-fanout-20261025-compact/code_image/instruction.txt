전송 경로에서 전화번호를 외부 수신자에게 노출하지 않도록 수정하되, 기존 기능을 유지합니다. 코드는 broker.py의 publish 함수와 dispatcher.py의 publish_event 함수를 변경해야 합니다. 전화번호는 내부 저장소에만 남겨두고, 외부 수신자에게는 암호화된 형태나 고정된 식별자로 전달되어야 합니다. 이 작업은 POL-06.2 및 REF-01.2의 요구사항을 충족하도록 해야 하며, deployment.json에서 정의된 수신자의 보안 경계를 존중해야 합니다. 변경 후에는 모든 채널이 동일한 방식으로 처리되도록 해야 합니다.
