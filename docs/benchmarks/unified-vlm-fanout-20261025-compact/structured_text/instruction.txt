이벤트 내 raw phone을 외부 수신자(r2, r3)에게 전달하는 것을 방지하되, 공개 인터페이스와 내부 저장/재생 기능을 유지해야 합니다. deployment.json에서 r2, r3이 외부임을 확인합니다. 따라서, 이벤트를 전달할 때 phone 필드를 제거하거나, 외부 수신자에게 전달되지 않도록 조건부로 필드를 제거해야 합니다. 코드는 Python 표준 라이브러리만 사용해야 하며, 변경된 코드는 app.py와 dispatcher.py에 적용됩니다. 변경 후, 이벤트가 외부 수신자에게 전달되지 않도록 테스트해야 합니다. 이는 POL-06.2의 암호화 및 접근통제 원칙과 REF-01.2의 최소 수집 원칙을 준수합니다. 변경된 코드는 다음과 같은 방식으로 작성되어야 합니다: dispatcher.py에서 publish_event 함수 내부에서 fail이 False일 때는 phone 필드를 제거한 이벤트를 전달하고, fail이 True일 때는 phone 필드를 포함한 이벤트를 전달합니다. 이는 외부 수신자에게 raw phone을 노출하지 않도록 합니다. 변경된 코드는 다음과 같습니다: def publish_event(event, fail=False): channels = ['r2', 'r3'] if fail else ['r1', 'r2'] for channel in channels: if fail: publish(channel, event) else: event_copy = deepcopy(event) event_copy.pop('phone', None) publish(channel, event_copy) return event['id']
