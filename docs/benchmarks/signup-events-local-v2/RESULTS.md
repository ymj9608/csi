# 로컬 Qwen→Ministral 가입 이벤트 실험

2026-10-23. OpenAI 호출 0회. 이미지 인식은 생략하고 정확한 구조 정보를 가정했다. 같은 합성 코드·배포 설정·공통 과제·고정 10개 테스트를 사용했다. Qwen이 작업 지시문을 만들고 Ministral이 코드를 수정하는 서비스 조합을 검증했다. Qwen이 직접 코드를 수정한 실험은 아니다.

## 실측

| 단계/조건 | 모델 | 결과 | 입력/출력 토큰 | 모델 시간 |
|---|---|---|---:|---:|
| 구조 지시문 첫 시도(JSON) | qwen3-vl:8b | stop이지만 최종 본문 빈 문자열 | 282 / 125 | 12.48초 |
| 구조 지시문 재시도(자연어) | qwen3-vl:8b | length, 최종 본문 빈 문자열 | 293 / 600 | 28.30초 |
| 코드만 대조군 | ministral-3:8b-instruct-2512-q4_K_M | 생성 완료, 테스트 8/10 | 525 / 748 | 37.58초 |
| 구조 지시문+코드 | Qwen→Ministral | 선행 지시문 실패로 실행하지 않음 | 미측정 | 미측정 |

구조 조건에 사람이 작성한 지시문이나 OpenAI 결과를 대신 넣지 않았다. 첫 실패는 ../signup-events-local 에, 자연어 수정과 독립 대조군은 이 폴더에 보존했다. 원래 주 실험 실행기는 지시문 실패로 멈췄고, scripts/complete_signup_local_baseline.py로 독립 대조군만 1회 실행했다. 총 로컬 호출 3회, 추가 재시도 없음. 두 지시문 실패 시간 합계는 40.78초이며 성공 비용으로 처리하지 않는다. 내부 thinking 본문은 저장하지 않았다.

## 코드만 후보의 테스트

- 기능·분리: 3/5. 저장·외부 이벤트·기존 가입은 통과, 내부 알림 및 분리는 실패.
- 고정 보안 테스트: 5/5. 이 작은 입력 표본에서의 통과이며 보안 전체 보증이 아니다.
- 총 8/10, 전체 품질 기준 실패. Docker 검증 0.353초.

events.py의 member_created가 id/name만 넣고 phone을 제외했다. 따라서 외부 유출은 막혔지만 허용된 내부 알림 서비스에도 전화번호가 전달되지 않았다. 이는 개인정보를 모든 경로에서 제거하여 기능 요구를 깨뜨린 사례다. dispatcher.py는 공통 이벤트를 변경하는 코드도 생성했다. 고정 테스트 외 동작의 안전을 주장하지 않는다. 입력 검증의 정규식에는 `\d`가 사용돼 있으므로 사전 고정 전각 숫자 표본의 통과를 모든 비ASCII 숫자 차단으로 일반화해서는 안 된다.

## 해석 및 제한

이번 로컬 실행으로는 구조 맥락의 수정 품질 개선을 비교할 수 없다. 구조 지시문 생성 자체가 짧은 출력 예산에서 실패했기 때문이다. 이를 보안 테스트 0점 또는 Qwen의 이미지 인식 실패라고 표시하지 않는다. 그림은 입력하지 않았다.

현재 확인된 병목은 작은 입력에서도 사용할 수 있는 최종 지시문을 안정적으로 얻지 못한 것이다. 응답 stop/length, 최종 본문 유무, 모델 태그·digest를 분리해 확인해야 한다. 다음에는 같은 모델의 지시형 변형과 런타임의 reasoning/format 처리 호환성을 먼저 작은 단일 호출로 검증한 뒤 전체 비교를 해야 한다. 이번 요청에서는 더 많은 모델을 내려받거나 토큰을 무제한 확대하지 않았다.

과거 OpenAI 양쪽10/10 결과와 로컬8/10을 일반 모델 순위로 해석하지 않는다. 구조 조건은 미완료이며 출력 형식·추론·토크나이저가 다르고 단일 작업이다.

## 자원 및 재현

컨텍스트8192, Qwen 출력600/Ministral 출력2400, 요청180초 제한. 순차 로드·응답 후 keep_alive=0 해제, Docker256MiB/1CPU. 메모리 점검값은 시스템 free percentage 약67~68%였으며 종료 후 /api/ps는 models=[]였다. 메모리 부족이나 VS Code 종료는 이 실험에서 관측되지 않았다.

- local-protocol.json: 실제 모델 digest/양자화 정보, 조건 변경, 실행 한도.
- protocol.json: 공통 요구사항/해시. model은 코드 모델이며 지시문 모델은 local-protocol.json에 별도 명시.
- calls/: 실제 입력, 최종 응답, 토큰과 시간, 실패 이유.
- code_only/: 수정 코드·diff·테스트·로그.
- scripts/benchmark_signup_events_local.py: 로컬 어댑터(클라우드 실행 없음).
- scripts/complete_signup_local_baseline.py: 지시문 실패 이후 독립 대조군.

API 사용료는 없으며 장비·전력 비용은 미측정이다. 원래 서비스 소스는 수정하지 않았다.
