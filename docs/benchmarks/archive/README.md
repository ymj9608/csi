# 이전 로컬 실험 기록

중복된 과제 스냅샷과 후보 디렉터리로 저장소 파일 수가 늘어나지 않도록 이전 실행을 ZIP으로 보관합니다. 실패·중단 기록도 포함하며 결과를 삭제하거나 성공 결과로 대체하지 않았습니다.

| 보관 파일 | 내용 |
|---|---|
| `windows-vlm-20261024.zip` | 최초 Windows 실행·대조군·후보 기록 |
| `windows-vlm-20261024-v2.zip` | 코드 인덱스·입력 범위 보정 실행 |
| `privacy-mvp-20261024-v1.zip` | 중단된 MVP 실행과 `deviation.json` |

각 ZIP은 원래 디렉터리 이름을 최상위 폴더로 포함합니다. `manifest.json`에 파일 수와 SHA-256을 기록했습니다. 모든 원본 파일과 ZIP 내부 바이트의 동일성을 확인한 뒤 보관했습니다. 원문 경로가 필요한 경우 해당 ZIP을 `docs/benchmarks`에 풀어 재현할 수 있습니다.

현재 비교·발표의 원시 근거는 `../windows-vlm-20261024-v3` 및 `../privacy-mvp-20261024-v2`에 그대로 있습니다. `../windows-vlm-architecture-v4`는 이후 만든 상세 이미지이며 v3 실험 결과와 혼동하지 않습니다.
