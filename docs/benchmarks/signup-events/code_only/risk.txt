Exposure path: signup.py now stores the submitted phone in the member record before dispatch; dispatcher.py previously forwarded the same event to every route, which would have sent that raw phone to topology.json's external analytics subscription via adapters.deliver(). The new dispatcher redacts any 'phone' key recursively for routes without phoneAllowed, while preserving raw phone for the internal notification route. Invalid phone input is rejected in signup.py with ValueError before save() or publish().
